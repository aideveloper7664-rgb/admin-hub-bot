# 🤖 AI Hub Telegram Bot

A Telegram bot that provides access to AI tools (DeepSeek, ChatGPT, NanoBanana, QR Generator) with channel verification.

## 🚀 Features

- 🔐 Channel join verification
- 🧠 DeepSeek AI integration
- 💬 ChatGPT integration  
- 🖼 NanoBanana image generation
- 📱 QR code generator
- 📊 User tracking & admin commands

## 🛠️ Setup

1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Set environment variable: `BOT_TOKEN`
4. Run: `python bot.py`

## 📦 Deployment

Deploy on Render with:
- Build Command: `pip install -r requirements.txt`
- Start Command: `python bot.py`
- Environment Variable: `BOT_TOKEN`

## 👑 Admin Commands

- `/stats` — Total users
- `/broadcast [msg]` — Send message to all users
